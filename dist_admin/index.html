Izin Google Drive Belum Diaktifkan

Google Apps Script pada akun treasury-sandbox@example.org memerlukan otorisasi DriveApp agar dapat menyimpan file struk bukti ke Google Drive.

Langkah Cepat Aktivasi (Hanya 1 Menit):
  1. Buka Google Sheets → Menu Ekstensi > Apps Script.
  2. Pilih fungsi testOtorisasiGoogleDrive → Klik Jalankan.
  3. Klik Tinjau Izin → Pilih akun → Izinkan (Allow).
  4. Klik Terapkan > Kelola Penerapan > Edit > Versi Baru > Terapkan.
